# Security Policy

## Supported versions

Outcome is currently a pre-1.0 controlled beta. Security fixes are applied to the
current `main` branch and the hosted controlled-beta service. Older commits and
pre-release builds are not supported; operators should update to the latest revision.

## Reporting a vulnerability

Report suspected vulnerabilities privately through
[GitHub Private Vulnerability Reporting](https://github.com/hancockalex21/outcome/security/advisories/new).
Please do not disclose vulnerabilities in a public GitHub issue, discussion, pull
request, log, screenshot, or other public channel.

Include the affected version or commit, impact, reproduction steps, and any suggested
remediation. Do not include live credentials, customer data, or other secrets. If a
credential may have been exposed, revoke or rotate it promptly rather than sending it
with the report.

Reports are reviewed on a best-effort basis. Outcome does not promise a fixed response
or remediation SLA during the controlled beta. We ask reporters to coordinate public
disclosure with the maintainers after a fix or mitigation is available.
